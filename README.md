
# Codebase Assistant

Codebase Assistant is a web application that allows developers to upload and explore project source code.

## Current Features

- Upload a project as a ZIP file
- Extract and store uploaded project files
- Store project metadata in PostgreSQL
- Browse the files contained in an uploaded project
- Select individual files and view their contents
- Display file information including filename, extension, and line count

## Technology Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Python, FastAPI
- Database: PostgreSQL
- Development: Docker, Git, GitHub

## Project Status

The current implementation focuses on project uploads, storage, and source-code exploration. Future development will expand its codebase analysis capabilities.
